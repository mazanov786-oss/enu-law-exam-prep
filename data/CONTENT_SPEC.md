Юрисдикция — Республика Казахстан: УК РК 2014 г., ГК РК (Общая часть), УИК РК, УПК РК, нормативные постановления Верховного Суда РК. Указывай точные статьи. Опирайся прежде всего на конспекты пользователя (они актуальны на 2026 г.); если в конспекте нет нужного — используй свои знания законодательства РК, при сомнении можно сверить на adilet.zan.kz. ## Выход 1: `data/content/<chunk>.json`
JSON-массив объектов, по одному на каждый вопрос твоего диапазона, строго в этом формате:

```json
{
  "id": "up-1-01",
  "notes": ["Уголовный закон"],
  "coverage": "full",
  "gaps": "",
  "articles": ["ст. 1 УК РК", "ст. 2 УК РК"],
  "plan": ["1. Понятие ...", "2. ..."],
  "answer": "Образцовый устный ответ на экзамене (200–400 слов). Можно **жирный** и переносы строк \\n. Структура: определение → признаки/виды → нормы (статьи) → пример/практика ВС РК → вывод.",
  "keywords": ["общественная опасность", "противоправность", "виновность", "наказуемость", "ст. 10 УК"],
  "cards": [{"front": "Что такое ...?", "back": "..."}],
  "mcq": [{"q": "...", "options": ["...", "...", "...", "..."], "correct": 2, "explain": "Почему верно, со ссылкой на статью"}],
  "cloze": [{"text": "Преступлением признается виновно совершенное {{общественно опасное}} деяние, запрещенное УК под угрозой наказания в виде {{штрафа|исправительных работ}} ...", "hint": "ст. 10 УК РК"}],
  "traps": ["Типичная ошибка студентов / ловушка экзаменатора"],
  "followups": ["Дополнительный вопрос, который может задать экзаменатор"]
}
```

Требования к полям:
- `notes`: названия заметок (без .md), где раскрыт вопрос.
- `coverage`: `full` (конспект раскрывает вопрос полностью), `partial` (частично), `none` (нет в конспектах).
- `gaps`: кратко, чего не хватает в конспекте (пусто при full).
- `plan`: 4–7 пунктов — план устного ответа.
- `answer`: полноценный устный ответ, по-русски, профессионально, со ссылками на статьи.
- `keywords`: 6–12 ключевых терминов/статей, которые должны прозвучать в ответе (используются для автопроверки — пиши короткие формы, напр. «ст. 32», «наличность», «действительность»).
- `cards`: 3–5 флеш-карточек (короткий вопрос → короткий точный ответ: определения, сроки, цифры, статьи).
- `mcq`: ровно 3 тестовых вопроса, 4 варианта, правдоподобные дистракторы (ловушки на сроках, возрастах, номерах статей). `correct` — индекс 0–3. Варьируй позицию правильного ответа.
- `cloze`: 2–3 предложения «с прочерком»: пропуски в `{{...}}`, допустимые варианты через `|`. Пропуск — ключевое слово/число/статья (1–3 слова).
- `traps`: 1–3, `followups`: 2–3.

Проверь валидность JSON: `node -e "JSON.parse(require('fs').readFileSync('data/content/<chunk>.json','utf8'))"`.

## Выход 2: `data/gaps/<chunk>.md`
Для каждого вопроса с coverage `partial` или `none` — готовый к вставке в Obsidian дополнительный конспект в стиле пользователя:

```markdown
## Вопрос <n>. <текст вопроса>
> [!info] Чего не хватало в конспекте: ...

<полноценный конспект: определения, признаки, классификации, таблицы markdown, статьи НПА РК, нормативные постановления ВС РК, пример/кейс>

**Связи:** [[Название заметки-источника]]
```
Если пробелов нет — файл с одной строкой «Пробелов нет».

В конце работы ответь кратко: сколько вопросов, сколько full/partial/none, пути к файлам.
