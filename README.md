# ⚖️ LEX.ENU — Экзаменационный тренажер по Уголовному и Гражданскому праву РК

Приложение для подготовки студента 2-го курса юридического факультета **Евразийского национального университета им. Л. Н. Гумилёва (г. Астана)** к зимней сессии по ключевым дисциплинам:
1. **Уголовное право РК (Общая часть)** (`UPRK 2208`, проф. Балтабаев К. Ж., Кияшева С. К.) — **135 вопросов**.
2. **Гражданское право РК (Общая часть)** (`GPRK 2207`, к.ю.н., ассоц. проф. Жаркенова С. Б.) — **73 вопроса**.

Все **208 официальных вопросов** силлабусов/УМК сверены с конспектами в Obsidian, актуализированы по **УК РК 2014 г.** (с изменениями 2026 г.) и **ГК РК (Общая часть)** и объединены в интерактивный тренажер.

---

## 🚀 Основные возможности приложения

### 1. 🎙️ Рандомайзер устных экзаменационных билетов (3 вопроса в 1 билете)
- **Формат экзамена ЕНУ:** генерирует билет из 3 разноплановых вопросов (Модуль 1 + Модуль 1/2 + Модуль 2).
- **Режимы жеребьёвки:**
  - *Умный подбор:* приоритет неизученным и слабым темам.
  - *Чистый рандом:* как на реальном экзамене.
  - *Отработка ошибок:* фокус на вопросах с низким баллом.
- **Голосовой ответ (Web Speech API `ru-RU`):** нажимаете микрофон и отвечаете устно. Система транскрибирует речь в реальном времени.
- **Мгновенная юридическая проверка:**
  - Автоматическое распознавание упомянутых **статей УК/ГК РК** и **ключевых терминов**.
  - Оценка по официальной буквенной шкале ЕНУ (`A` / `B` / `C` / `D` / `F`) с расчётом GPA.
  - Сопоставление с эталонным устным ответом (200–400 слов) и планом ответа.
  - Разбор **ловушек экзаменатора** и **дополнительных вопросов на засыпку**.
- **ИИ-экзаменатор (Gemini):** возможность подключить API-ключ Gemini в настройках для развернутой рецензии от виртуального профессора ЕНУ.

### 2. ⏱️ Шкала готовности и дедлайн-трекер
- Таймеры обратного отсчета до экзаменов по УП и ГП.
- Расчет суточного темпа (сколько вопросов/билетов в день нужно повторять).
- Индекс готовности к сессии (%) и прогноз итоговой оценки.

### 3. 📝 Режим «Тесты с ловушками» (MCQ)
- Свыше **624 тестовых вопросов** (по 3 на каждый экзаменационный вопрос).
- Мгновенный разбор: точное указание статьи кодекса и объяснение, почему остальные варианты — дистракторы.
- Режим фильтрации: «Только ошибки».

### 4. ✍️ Режим «Прочерк» (Тренажер диспозиций)
- Вписывание пропущенных сроков, возрастов, сумм и юридических категорий вручную или **голосом**.
- Нечеткое сопоставление (учитывает падежные окончания и синонимы).

### 5. 🧠 Интервальные флеш-карточки (Spaced Repetition)
- Свыше **800 карточек** по системе Лейтнера (5 коробок запоминания).
- Карточки с определениями, классификациями и ключевыми цифрами.

### 6. 🛡️ Журнал разбора ошибок и Справочник капканов
- Автоматическая фиксация всех неправильных ответов из билетов, тестов и прочерков.
- База специфических ловушек квалификации (например, солидарная гарантия по ст. 329 ГК РК vs субсидиарное поручительство по ст. 330 ГК РК; запрет условного осуждения при коррупции по ст. 63 УК РК и др.).

### 7. 📖 Полный каталог 208 вопросов и эталонов
- Быстрый поиск по статьям, номерам вопросов и ключевым словам.
- Сверка с конспектами Obsidian (`full` / `partial` / `none`).

## ☁️ Развертывание на Vercel

Проект полностью оптимизирован для Vercel (Next.js 15 App Router, TypeScript, Tailwind CSS, 0 внешних баз данных, состояние сохраняется в `localStorage` с возможностью экспорта/импорта JSON):

### Вариант 1. Через Vercel CLI (1 команда):
```powershell
npx vercel
```
Следуйте подсказкам в терминале (выберите дефолтные настройки Next.js). Для деплоя в production:
```powershell
npx vercel --prod
```

### Вариант 2. Через GitHub:
1. Создайте репозиторий на [github.com](https://github.com) (например, `enu-law-exam-prep`).
2. Запушьте код:
   ```powershell
   git init
   git add .
   git commit -m "Initial commit: ENU Law Exam Prep"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/enu-law-exam-prep.git
   git push -u origin main
   ```
3. В панели [vercel.com](https://vercel.com) нажмите **Add New Project** → импортируйте репозиторий → нажмите **Deploy**.
